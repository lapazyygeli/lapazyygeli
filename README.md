## Main Projects

- **[AlphabetNinja](https://github.com/lapazyygeli/letter-tile-game.git):** A fullstack word game where players drag letter tiles onto an unlimited game board to form one chain of connected words using English words. Features secure JWT-based authentication with short-lived access tokens stored in memory and refresh tokens in httpOnly cookies, automatic token renewal and persistent personal statistics and leaderboards.

- **[RoomDb](https://github.com/lapazyygeli/room-db):** Android application designed to help users manage their reading lists.
